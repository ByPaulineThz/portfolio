React Vite

Boxy - Générateur de Box Shadow CSS

Un outil web interactif conçu pour personnaliser, visualiser et exporter facilement des ombres CSS en temps réel. Aucune IA utilisée pour ce projet.

Rôle
UI Designer, Développeur front-end
Livrables
Interface React
Outils utilisés
React, Redux Toolkit, Vite, VS code, Tailwind, Github

Contexte du projet

Ce projet est né d'une formation React suivie sur Udemy, pour mettre en pratique mes compétences en développement front-end au-delà de la théorie. Je suis allée plus loin que l'exercice de base pour en faire une vraie pièce de portfolio : personnalisation du design, organisation du code, et mise en ligne.

Pourquoi ces choix techniques

  • React permet à l'interface de réagir instantanément : dès qu'on modifie un réglage (flou, taille, couleur), l'aperçu se met à jour en temps réel.
  • Redux Toolkit garde en mémoire tous les réglages de l'ombre (position, flou, étendue, couleur, opacité) au même endroit, pour être sûre qu'ils restent toujours cohérents entre eux et avec le code CSS généré.
  • Vite rend le développement plus rapide et plus fluide : le site se recharge presque instantanément à chaque modification, ce qui facilite les allers-retours pendant la création.

Défi principal

Le plus difficile a été de faire en sorte que tout bouge ensemble, sans accroc : dès qu'on déplace un curseur, l'aperçu visuel ET le code CSS affiché doivent se mettre à jour instantanément et rester synchronisés. C'est ce qui m'a poussée à mieux structurer mes données avec Redux Toolkit, plutôt que de tout gérer de façon éparpillée.

Ce que j'en retiens

Au-delà du suivi du cours, ce projet m'a permis de manipuler concrètement la gestion des données avec Redux Toolkit, et de comprendre l'intérêt d'un outil moderne comme Vite sur un cas concret plutôt que théorique.
